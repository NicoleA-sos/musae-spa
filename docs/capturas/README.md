# Capturas para la entrega

Antes de la entrega final, agrega capturas de pantalla sin correos personales, enlaces de recuperación, tokens ni claves.

Incluye, como mínimo:

1. Página de inicio o catálogo de servicios.
2. Selección de fecha y horario para una reserva.
3. Pago simulado aprobado, con código de operación.
4. Cancelación de una reserva y reembolso simulado cuando aplique.
5. Panel de administración.
6. Vista en celular.

Guárdalas en esta carpeta con nombres claros, por ejemplo `inicio.png`, `reserva.png`, `pago-aprobado.png`, `cancelacion-reembolso.png`, `administracion.png` y `movil.png`.
